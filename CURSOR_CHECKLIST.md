# Cursor Checklist — Definition of Done

## At project creation
- [ ] New `suryasathi` folder/repository created during the hackathon window.
- [ ] These Markdown docs stored in the project root.
- [ ] ThreeUI Kage prompt copied by the user and pasted before `CURSOR_START_PROMPT.md`.
- [ ] Cursor inspected an empty/new project folder and created Next.js in that folder, not a nested second app.
- [ ] Dependency versions recorded and compatible.
- [ ] First real commit made; no fake/backdated history.

## Landing experience
- [ ] Original SuryaSathi branding/content, not Kage temple imagery.
- [ ] Cinematic canvas works in desktop browser.
- [ ] At least one polished scroll/camera transition.
- [ ] Main CTA works.
- [ ] Mobile layout and WebGL fallback work.
- [ ] Reduced-motion/skip controls work.

## Product flow
- [ ] User can reach analysis without login.
- [ ] Bill and quote can be uploaded or manually entered.
- [ ] Extracted fields can be reviewed/edited.
- [ ] Roof and obstacles accept valid geometry.
- [ ] Backend can calculate panel arithmetic and a generation estimate or explicitly state why not.
- [ ] X-Ray includes source/reason/next action.
- [ ] Demo data visibly labelled.
- [ ] Report is printable or downloadable.

## Backend/AWS
- [ ] `/health` responds from deployed backend.
- [ ] Actual AWS service is invoked in the core flow.
- [ ] CORS works from deployed frontend.
- [ ] No secret keys exposed in browser bundle or repo.
- [ ] PII not printed to logs.
- [ ] Error/manual fallback works when Textract/Bedrock/PVGIS unavailable.

## Submission
- [ ] Public GitHub repo.
- [ ] README updated to reflect only implemented features.
- [ ] AI tool usage disclosed.
- [ ] Sources/licences/limitations written down.
- [ ] YouTube demo <3 minutes and tested signed out.
- [ ] Demo shows actual AWS operation, not only a diagram.
- [ ] Link opens in incognito.
- [ ] Submit before the official deadline and save confirmation.
