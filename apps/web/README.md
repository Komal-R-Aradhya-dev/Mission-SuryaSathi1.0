# SuryaSathi web

Frontend for the Solar Quote X-Ray. From the repository root, see `README.md`.

```bash
cd apps/web
npm install
npm run dev
```

Set `NEXT_PUBLIC_API_BASE_URL` only when Adish’s API is reachable. Copy `.env.example` to `.env.local`. Do not put AWS credentials in any `NEXT_PUBLIC_` variable.

The cinematic terrace is original procedural geometry. It is not a yield model.
