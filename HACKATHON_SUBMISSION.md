# Hackathon Rules and Submission Checklist

## Current official context

- Event: WeMakeDevs × AWS Environmental Hacks 2026, part of the Bharat Builds Tour.
- Date window: October 8–11, 2026.
- Team size: up to 4; each teammate must qualify/register separately.
- Track: Waste & Energy. Official track examples explicitly include rooftop solar.
- AWS: project must use at least one AWS open-source tool **or** be deployed on AWS; the demo video must show AWS use. Our chosen path is a real AWS deployment.
- Allowed: open-source libraries, frameworks, public APIs, boilerplate and starter templates; AI coding tools are allowed but must be listed in the writeup.
- Prior work: learning/planning before opening is allowed, but the actual project must be built during the event. Do not pass off an old project as new; keep genuine Git history.
- Deliverables: public repository, YouTube demo under 3 minutes (public/unlisted and tested while signed out), short writeup describing problem/build/AWS.
- Judges evaluate what is submitted; no live demo/call. Anything not shown in the video may receive no credit.

## Repo proof

- New repository/project created after kickoff.
- Natural, real commit history; no backdating or fake commits.
- Public repository with setup/deployment instructions.
- `.env` and secrets excluded.
- Third-party code/data/assets credited and licensed.
- AI coding tools listed honestly.
- README includes limitations and real evaluation results only.

## Demo video plan (target ~2:45)

- 0:00–0:15 — Problem and homeowner.
- 0:15–0:35 — Bill/quote input and field review.
- 0:35–1:00 — Roof model and visual context.
- 1:00–1:35 — Main Claim-vs-Physics X-Ray on a real backend response.
- 1:35–2:00 — Explain one important status with evidence/source and next question.
- 2:00–2:25 — Show the actual AWS-backed processing/deployment/logging; hide all secrets/PII.
- 2:25–2:45 — Before You Pay report and concise impact statement.

Do not fabricate metrics, display sample inputs as actual users, or claim annual shading accuracy not implemented.

## Final submission checklist

- [ ] Public GitHub repository accessible in signed-out browser.
- [ ] Latest code/build and setup instructions verified.
- [ ] Live URL works in a fresh/incognito browser.
- [ ] Core input → audit → evidence flow works.
- [ ] AWS service actually invoked and can be shown on camera.
- [ ] Demo under 3 minutes, YouTube public/unlisted, link works signed out.
- [ ] Short writeup covers problem, implementation and AWS role.
- [ ] AI tools and reused libraries/assets correctly disclosed.
- [ ] Licence/attribution files included.
- [ ] No credentials, real bills, or personal identifiers exposed.
- [ ] Submit early and save confirmation.
